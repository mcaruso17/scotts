## Key points / insights (one sentence each)

- The series has moved from simple text-reclassification demos (e.g. GPT-4o-mini
  labeling) toward full research pipelines with real econometric stakes.
- Using Claude Code for research *creates new problems even as it solves old
  ones* — and can do so even when it does not actually reduce time spent.
- **Referee 2** is a five-audit protocol run by a *fresh* Claude instance that
  never saw the work, precisely so the builder cannot grade its own pipeline.
- **Referee 2 never modifies author code** — it writes its own independent
  replication scripts, keeping the audit genuinely independent.
- **Blindspot** is a "peripheral vision" audit that surfaces overlooked problems
  ("vices") and missed opportunities ("virtues") in a research output.
- **Bibcheck** verifies bibliographies by dispatching parallel narrow-focus
  agents to check citations against canonical sources.
- Good agent use is *iterative dialogue*: Claude executes when the next move is
  clear and surfaces ambiguity when it isn't — the conversation is the work.
- The Odd Couple project deliberately replicates a pipeline across R, Python and
  Stata from scratch to catch language- and package-specific errors.
