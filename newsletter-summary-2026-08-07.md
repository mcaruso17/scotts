# Scott Cunningham Newsletter — Summary

**Post:** "How to Improve Understanding with Claude Code"
**Publication:** Scott's Mixtape Substack
**Date:** August 7, 2026
**Link:** https://causalinf.substack.com/p/how-to-improve-understanding-with

## Main topics / themes
- The shift from "verification is the new bottleneck" to "**understanding** is the new bottleneck" in AI-assisted research.
- The economics of research production once AI agents drive the marginal cost toward zero.
- Whether the human understanding that used to come free with doing the work survives when an agent does the work.
- A concrete workflow experiment — a Claude Code `/quiz` skill — for rebuilding understanding on purpose.

## Key points / insights
- AI agents cut the marginal cost of *producing* research to roughly zero, raising output and creating new "surplus" while shrinking the time each project takes.
- Historically, understanding a piece of work was an almost automatic byproduct of producing it — possibly an *externality* of human labor, like pollution from manufacturing.
- When an agent produces the work, that byproduct understanding is no longer guaranteed, and saved time may not automatically refill it.
- Verification and understanding are different: agents may soon verify as well as they produce, yet the human still may not understand the result.
- Delegating to an agent is a principal–agent problem — you trust it did the work well but can't hold a machine accountable, so it must actively help you understand or not be used at all.
- Reviewing changes purely as git diffs (Paul Goldsmith-Pinkham's "the unit of verification is the git diff") tends to become passive skimming that accumulates "cognitive debt" instead of clearing it.
- "Zero errors" should be treated as a hard **constraint**, never an objective function, because an accepted error rate scales badly when research output is highly elastic.
- Cunningham's remedy is a `/quiz` Claude Code skill: the agent makes teaching slides and then asks him one-at-a-time multiple-choice questions — modeled on corporate "training video + quiz" modules — layered on top of staged checklists and diff review.
- The stated goal is to keep the agent as a *co-pilot* that helps him keep learning, not an *autopilot* that runs while he sleeps.
