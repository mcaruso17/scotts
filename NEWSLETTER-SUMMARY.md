# Scott Cunningham — "Mixtape" Substack: Latest Summary

_Compiled 2026-06-29. Note: `causalinf.substack.com` is blocked by this
environment's egress policy, so this summary is built from web-search indexing
of the newsletter, its notes, and the companion `MixtapeTools` repository
rather than a direct read of the live archive. The most recent post content
that could be verified through search dates to roughly April 2026._

## Main themes
- **AI agents are reshaping how researchers work** — the newsletter's stated focus.
- **Claude Code for quantitative / empirical social science** — an ongoing,
  hands-on video + essay series.
- **Verification over production** — using AI to *audit* research, not to write
  the referee report.
- Causal inference / econometrics teaching (the long-running core) plus the
  "Mixtape with Scott" oral-history podcast.

## Key points
- AI agents unbundle the historically fused tasks of *producing* research and
  *verifying* it; the researcher's new core job is verification.
- The advocated stance is **Claude as a thinking partner**, steered iteratively,
  not as an autonomous pipeline ("the dialogue is the work").
- **Referee 2** is a five-audit protocol run in a fresh terminal by a Claude
  instance with no prior context (code, cross-language replication, directory
  structure, output automation, econometric specification).
- **Blindspot** is a complementary perception audit that finds what the author
  cannot see (problems and missed opportunities on a 2×2 grid).
- Cross-software replication (R = Stata = Python to 6+ decimals) catches
  single-language bugs.
- A recent note describes using AI agents in peer review *without* having the
  agent write the referee report.
