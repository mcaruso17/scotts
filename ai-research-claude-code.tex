\begin{abstract}
\noindent This document summarizes the main concepts behind the use of AI
coding agents---particularly Anthropic's \textbf{Claude Code}---in scientific
and empirical research. It draws on the broader 2025--2026 literature on
agentic AI for science and on the practical, applied perspective developed by
economist Scott Cunningham in his \emph{Scott's Mixtape} newsletter, whose
latest episode is summarized in the appendix. The goal is to map how
conversational, terminal-based AI agents are reshaping the research workflow
from data cleaning through replication, reproducibility auditing, and writing.
\end{abstract}

\section{What Claude Code Is}
Claude Code is a terminal-based (CLI) ``agentic'' assistant built on
Anthropic's Claude models. Unlike a chat window that only returns text, an
agent can read and edit files, run code, inspect outputs, and iterate toward a
goal across many steps. For researchers this turns the model from a
question-answering tool into a collaborator that operates directly inside the
project repository---reading data, executing scripts in R, Stata, or Python,
and revising its own work in response to errors.

\section{Main Themes: Why AI Agents Matter for Research}
\begin{itemize}
  \item \textbf{From autocomplete to autonomous workflows.} The shift is from
  line-by-line code suggestion to delegating whole multi-step tasks (clean,
  estimate, plot, interpret) to an agent that closes the loop itself.
  \item \textbf{Reproducibility as a first-class use case.} Agents can re-run
  published code, reconcile results with reported tables, and flag
  discrepancies---scaling replication work that was previously too costly to
  perform at volume.
  \item \textbf{Cross-language portability.} The same analysis can be
  translated and cross-checked across R, Stata, and Python, exposing
  language-specific bugs and confirming robustness.
  \item \textbf{Lower bar to advanced methods.} Researchers can apply
  cutting-edge estimators (e.g., modern difference-in-differences) without
  hand-coding every detail, while still being responsible for the
  interpretation.
  \item \textbf{Tighter, more consistent output.} Empirical 2026 studies report
  that coding agents land near the human-median result but with markedly
  smaller dispersion and fewer extreme outliers.
\end{itemize}

\section{Key Applications in the Research Workflow}
\begin{enumerate}[label=\arabic*.]
  \item \textbf{Data preparation:} cleaning, merging, reshaping, and building
  data-quality gates that must pass before estimation proceeds.
  \item \textbf{Estimation:} implementing and running econometric estimators
  (panel methods, continuous-treatment diff-in-diff, event studies) and
  comparing competing packages.
  \item \textbf{Reproducibility \& code audits:} systematic protocols (e.g., a
  ``Referee 2'' style audit) that verify whether a paper's code actually
  produces its claimed results across languages.
  \item \textbf{Literature \& paper parsing:} reading PDFs of academic papers to
  extract methods, assumptions, and target parameters.
  \item \textbf{Writing \& presentation:} drafting LaTeX/Quarto documents,
  building slide decks, and automating reporting around the analysis.
  \item \textbf{Project configuration:} \texttt{CLAUDE.md} templates, skills,
  hooks, and rules that encode a lab's conventions so the agent behaves
  consistently across sessions.
\end{enumerate}

\section{Best Practices and Guardrails}
\begin{itemize}
  \item \textbf{Verification over trust.} Agents can fabricate plausible but
  wrong outputs when data or code is missing; results must be checked, not
  assumed. Adopt a ``zero-error'' / always-verify philosophy.
  \item \textbf{Human accountability.} Interpretation, identifying assumptions,
  and final conclusions remain the researcher's responsibility; the agent is an
  instrument, not an author.
  \item \textbf{Reproducible scaffolding.} Version control, explicit project
  rules, and audit protocols make agent contributions inspectable and
  repeatable.
  \item \textbf{Know the failure modes.} Reproducibility gains are strong when
  data and code exist; accuracy degrades sharply on genuinely
  non-reproducible tasks.
\end{itemize}

\section{The Scott Cunningham Perspective}
Scott Cunningham (Professor of Economics, Baylor University; author of
\emph{Causal Inference: The Mixtape}) has become a prominent applied voice on
using Claude Code for empirical social science. His \emph{Scott's Mixtape}
Substack pairs causal-inference teaching with an ongoing, hands-on series of
walkthroughs on AI-assisted research: comparative audits of causal-inference
packages, cross-language replication, PDF-reading skills for papers, mobile
``Dispatch'' workflows, and reflective essays on AI-assisted discovery. He
also maintains the open-source \texttt{MixtapeTools} repository of coding,
teaching, and presentation utilities for AI-assisted research.

\section{Outlook}
Agentic AI is moving from a productivity aid to part of the methodological
infrastructure of empirical research. The frontier questions are no longer
``can the model write code?'' but ``how do we audit, attribute, and trust what
the agent produced?''---making reproducibility tooling, verification
protocols, and clear human accountability the central design problems for the
next phase.
