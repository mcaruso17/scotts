\begin{abstract}
\noindent This document summarizes the main concepts behind the use of AI agents
in empirical research, drawing on the work of the economist Scott Cunningham
(\emph{Causal Inference: The Mixtape} / \emph{The Remix}) and his ongoing series
on using \textbf{Claude Code} for practical quantitative social science. It opens
with a short summary of the most recent newsletter, then organizes the recurring
ideas into a reusable methodology: agentic coding as a dialogue, cross-language
replication as default verification, the ``Referee~2'' five-audit protocol,
reproducibility and documentation discipline, and the likely implications of AI
agents for scholarly publishing.
\end{abstract}

\section{Why AI Agents Matter for Research}
% ================================================================

Coding agents such as Claude Code can now read a paper, plan an analysis, write and
run code across languages, inspect outputs, and revise---inside a single terminal
session. For empirical social science this shifts the researcher's role from typing
code to \emph{steering, interrogating, and verifying} an agent that does the typing.
The central claim running through Cunningham's work is that this is not merely a
speed-up: used well, agents can raise the \emph{reliability} of empirical research by
making rigorous checks cheap enough to run by default.

\begin{keybox}{The governing principle}
``The dialogue is the work, not just the delivery mechanism for the work.''
Claude is treated as a \emph{thinking partner}, steered iteratively---not as an
autonomous black box that is handed a task and trusted with the result.
\end{keybox}

\section{Core Concepts and Methods}
% ================================================================

\subsection{Agentic coding as a steered dialogue}
The workflow prizes clarity over automation. Rather than one-shot prompts, the
researcher and agent iterate: state the estimand and identification strategy, plan
the pipeline, execute, inspect, and revise. Persistent context lives in a
\texttt{CLAUDE.md} project-memory file so that intent, conventions, and prior
decisions survive across sessions.

\subsection{Cross-language replication as default verification}
The signature idea. Coding errors in R, Stata, and Python are \emph{language- and
package-specific}, so they are plausibly \emph{independent}. Re-implementing the same
pipeline in all three languages and comparing intermediate results at each stage
turns that independence into a rigorous check:
\begin{itemize}[leftmargin=1.4em,itemsep=2pt]
  \item When non-random quantities (e.g., $R^2$, coefficients) agree to many decimal
        places across languages, confidence is high.
  \item When they diverge, a bug or an undocumented data decision is exposed.
\end{itemize}
In one audit of a published paper on Brazil's psychiatric reform, an agent wrote
roughly \textbf{96 scripts across three languages in a single session} and surfaced
real problems: a variable that mechanically declined over time, large treatment
vs.\ control imbalance on nearly half of the background characteristics, and
undocumented duplicate records.

\subsection{``Referee 2'': the five-audit protocol}
\emph{Referee~2} is a health-inspector protocol for a finished project. It runs in a
\textbf{fresh terminal}, executed by a Claude instance that has \emph{never seen the
work}---structural independence enforcing the rule that ``you cannot grade your own
homework.'' Critically, Referee~2 \emph{never edits the author's code}; it writes only
independent replication scripts and dated reports.

\begin{center}
\begin{tabular}{@{}p{0.30\linewidth}p{0.62\linewidth}@{}}
\toprule
\textbf{Audit} & \textbf{What it checks} \\
\midrule
Code audit & Bugs, missing values, merge diagnostics. \\
Cross-language replication & R/Stata/Python results must match to $\sim$6+ decimals. \\
Directory audit & Folder structure and replication-readiness. \\
Output automation audit & Tables/figures generated programmatically, not by hand. \\
Econometrics audit & Identification, standard errors, parallel-trends checks. \\
\bottomrule
\end{tabular}
\end{center}

\subsection{Complementary tools}
\begin{itemize}[leftmargin=1.4em,itemsep=3pt]
  \item \textbf{Blindspot} --- a ``peripheral vision'' audit that surfaces overlooked
        problems and missed opportunities (unasked questions, unexploited strengths).
  \item \textbf{Bibcheck} --- many narrow-focus agents, one per citation, to catch
        transcription errors and mixed bibliography entries.
  \item \textbf{Split-PDF} --- a deep-read protocol that splits a paper into small
        chunks with incremental note extraction to curb hallucination.
  \item \textbf{Read-paper protocol} --- a disciplined way to ingest a paper before
        replicating or refereeing it.
\end{itemize}

\subsection{Communication: the ``Three Laws'' of presentation}
The same agentic discipline extends to communicating results:
\begin{enumerate}[leftmargin=1.6em,itemsep=2pt]
  \item Beauty is an attention-earning mechanism.
  \item Cognitive load is the enemy.
  \item Slides serve the spoken words, not the reverse.
\end{enumerate}
Corollaries: titles are \emph{assertions}, not labels; one idea per slide. Supporting
commands (e.g.\ \texttt{/compiledeck} for Beamer, a \texttt{/tikz} skill with collision
detection) embed this rhetoric into the toolchain.

\subsection{Documentation discipline}
\begin{keybox}{The central tenet}
``If it's not documented, it didn't happen.'' Every audit produces a dated report
filed in a \texttt{correspondence/} directory, so the reasoning behind each decision
is recoverable later.
\end{keybox}

\section{Implications: Reproducibility and Publishing}
% ================================================================

Two threads run through this body of work. First, \textbf{reproducibility becomes
cheap}: because an agent can replicate a pipeline from scratch in multiple languages,
independent verification can be a routine step rather than a heroic one. Second,
Cunningham speculates---in what he calls ``Claude Code fan fiction''---about the near
future of \textbf{scholarly publishing}, where agentic referees, automated
reproducibility audits, and cross-language replication reshape how manuscripts are
checked and how quickly errors are caught. The consistent message is one of
\emph{augmentation with guardrails}: agents multiply a researcher's reach, but their
value depends on independent verification, explicit identification strategy, and a
documented paper trail.
