\begin{abstract}
\noindent This document summarizes the main concepts surrounding the use of
artificial intelligence in empirical research, with particular emphasis on
\textbf{coding agents} and the workflow that has crystallized around
\textbf{Claude Code}. It draws on the themes developed by economist
Scott Cunningham in his ongoing Substack series documenting the use of Claude
Code for quantitative social science. The central claim is that AI agents have
\emph{lowered the marginal cost of producing empirical research} while shifting
the researcher's scarce attention from \emph{production} to \emph{verification}.
\end{abstract}

\section{Context and Motivation}

Since late 2025, coding agents such as Claude Code and Codex have moved from
novelty to standard equipment in many empirical research workflows. The
recurring observation across practitioners is economic in nature: the
\textbf{marginal cost of producing analysis}---writing data-cleaning scripts,
estimating models, generating tables and figures, drafting prose---has fallen
dramatically. What was once a bottleneck (translating an idea into working,
reproducible code) is now cheap and fast.

This shift raises a productivity paradox for research: if producing results is
nearly free, then the binding constraint becomes \emph{knowing which results to
trust}. The scarce resource is no longer labor but judgment.

\section{Core Concepts}

\subsection{The Coding Agent}
A coding agent is an AI system that operates directly in a developer
environment---reading and writing files, executing code, inspecting output, and
iterating---rather than merely returning text in a chat window. Claude Code is
an agentic command-line tool of this kind: it can navigate a repository, run a
regression, read the error message, and fix the script, closing the loop
between intention and execution.

\subsection{Falling Marginal Cost of Production}
The signature economic theme of the series. When output becomes cheap,
\textbf{aggregate output rises}, but so does the \textbf{aggregate quantity of
errors} if verification does not scale with production. More analyses, more
robustness checks, and more variants are produced---but each still needs
checking.

\subsection{Unbundling Production from Verification}
Historically, \emph{producing} a result and \emph{verifying} it were bundled
into a single act performed by the same researcher: to obtain a coefficient you
had to write the code, and in writing it you understood it. Agents break this
bundle. A result can now appear without the researcher having authored the
steps that produced it, making \textbf{deliberate verification} a distinct,
newly essential activity.

\subsection{Which Errors Matter}
Not all mistakes are equal. A key distinction is between errors that are
cosmetic or self-correcting and errors that corrupt the substantive conclusion
(and thus the researcher's \emph{human capital}---their understanding and
reputation). The productive question is not ``did the agent make a mistake?''
but ``does this mistake matter for what I claim to know?''

\subsection{Stale Code, Deprecation, and the Canon}
A practical hazard: over a long project the analytical sample or code silently
drifts (e.g., an $N$-observation sample becomes $N+k$). This motivates a
\textbf{structured workflow}---a stable ``canon'' of code and results---so that
changes are intentional and traceable rather than accidental.

\section{The Claude Code Research Workflow}

The following practices recur as informal ``best practices'' for using an agent
in serious empirical work:

\begin{enumerate}[leftmargin=1.4em]
  \item \textbf{Reproducibility first.} Keep a canonical, re-runnable pipeline
        so any result can be regenerated from raw data on demand.
  \item \textbf{Prose is not constraints.} Natural-language instructions are
        soft; genuine guarantees come from tests, assertions, and checks encoded
        in the pipeline, not from politely asking the model.
  \item \textbf{Verification as a first-class step.} Budget explicit time and
        code for checking results, because production no longer forces it.
  \item \textbf{Version control and provenance.} Track what changed, when, and
        why, so sample or specification drift is caught early.
  \item \textbf{Keep a human in the loop on interpretation.} Delegate
        execution; retain judgment about identification, estimators, and meaning.
\end{enumerate}

\section{An Illustrative Empirical Project}

The series is anchored by a live research project (with Caitlin Myers)
estimating the effect of Texas House Bill 2---which closed roughly half the
state's abortion clinics---on marriage rates. Methodologically it uses
\textbf{continuous difference-in-differences}, with treatment defined as the
\emph{change in distance} to the nearest clinic. Recent installments wrestle
with concrete econometric judgment calls that agents cannot resolve for the
researcher, including:
\begin{itemize}[leftmargin=1.4em]
  \item choice and interpretation of estimator (e.g., a Poisson vs.\ linear
        specification);
  \item confounders that could threaten the \textbf{parallel-trends}
        assumption; and
  \item what level of residual uncertainty one is ``willing to live with.''
\end{itemize}
The point is illustrative: the agent accelerates every mechanical step, while
the substantive identification decisions remain irreducibly human.

\section{Implications for Researchers}

\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Skill reallocation.} Time saved on coding is reinvested in
        research design, verification, and interpretation.
  \item \textbf{New literacy.} Researchers must learn to \emph{supervise} an
        agent---prompting, reviewing diffs, and auditing output---as a core
        methodological skill.
  \item \textbf{Reproducibility as insurance.} A disciplined, re-runnable
        pipeline is the main defense against the increased error volume that
        cheap production creates.
  \item \textbf{Verification is the new bottleneck.} As production approaches
        zero cost, the comparative advantage of a researcher shifts decisively
        toward judgment about whether a result is correct and meaningful.
\end{itemize}

\section{Summary}

AI coding agents, exemplified by Claude Code, are reshaping empirical research
less by inventing new methods than by \textbf{collapsing the cost of executing
existing ones}. This is genuinely liberating, but it relocates the researcher's
essential work: from writing analysis to \emph{vouching} for it. The durable
lesson from Scott Cunningham's series is that the future-proof researcher pairs
aggressive use of agents for production with disciplined, deliberate
verification---keeping human judgment firmly in charge of what counts as
knowledge.
