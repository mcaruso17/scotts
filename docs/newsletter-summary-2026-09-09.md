## Main topics / themes

- **Connectors in Claude Code** — what they are, where to find them, and how they extend the agent.
- **MCP (Model Context Protocol)** — the "piping" standard behind connectors.
- **The "harness" idea** — Cunningham's vision of a staged, visual environment for causal-inference research.
- **Solopreneurs & economic growth** — how the same tooling powers one-person firms and may lift productivity.

## Key points / insights

- Connectors are the mechanism that lets Claude Code run from the **phone app** and reach **cloud services**, not just the local machine.
- The connector directory works like an **app store** with roughly **4,000+** entries (about **451** under "Code" alone), split into vetted and lightly-reviewed **Community** connectors ("buyer beware").
- **MCP** is an open standard letting AI apps securely connect to external data/tools for real-time info and actions.
- **Financial-services** connectors (Stripe, PayPal, QuickBooks, Gusto, Dropbox) could let a single person run a real small business; direct **bank** API access is notably absent, likely for security reasons.
- Cunningham personally uses connectors mainly to **search Dropbox from the phone**, and sees latent research value he hasn't fully unlocked yet.
- His hoped-for **causal-inference harness** is checklist-driven (echoing his book), deeply **visual**, and aimed at an **Apple Vision Pro** interface to recover the "sight" he feels he lost when delegating coding to agents.
- The harness goal reduces to three obligations: **production, verification, and understanding**.
- **Solopreneurs** (1-employee firms) are growing fast per Stripe data, some reaching **$1M–$10M** revenue — plausibly enabled by agent + connector tooling, with implications for **labor productivity** and **per-capita income**.
